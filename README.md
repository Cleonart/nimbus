# 🌩️ Nimbus ERP

**Nimbus** is an **open-source, free ERP** system designed to be **modular, extensible, and Odoo-like**, but built with **Spring Boot + Kotlin** ⚡.  
Use it for business management, learn from it, or contribute to make it better 🚀.

---

## 🏁 Getting Started

### ✅ Prerequisites

- ☕ **JDK 17** installed
- 🦄 **Kotlin** installed locally
- 🛠️ **VS Code Extensions**:
  - Kotlin Formatter
  - Extension Pack for Java
  - Spring Boot Extension Pack

### ▶️ Run the Project

1. Build the project:
   ```bash
   ./gradlew build
   ```
2. Start the app:
   ```bash
   ./gradlew bootRun --info
   ```
